# FridgeChannel Dashboard UI 设计规范

## 标题与说明文字

- 页面或内容分区标题下方的说明文字，默认使用父容器的完整可用宽度。
- 不得为标题说明文字设置固定像素宽度、`ch` 字符宽度或其他 `max-width` 限制。
- 当标题右侧存在操作按钮时，按钮保留在标题行；说明文字必须另起一行，并横跨整个内容区域。
- 说明文字可以根据容器宽度自然换行，但不应通过人为缩窄文本列来增加换行。
- 只有在明确的阅读型长文场景中，经过设计确认后，才可以为正文设置行长限制；该例外不适用于管理后台的标题说明文字。

### 实现约定

- 配置和管理页面统一使用 `CfgSection`。
- `CfgSection` 的 `sub` 与 `desc` 均为全宽行：`width: 100%`、`max-width: none`。
- 新增标题说明样式时，应复用这一规则，不得在单个页面内重新添加宽度上限。
