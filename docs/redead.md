# Klaviyo Segment 中文对照

Segment discount configuration 页面中常见分群的中文名称与用途说明。

| 英文名称 | 中文名称 | 说明 |
| --- | --- | --- |
| Second Order Push | 二次下单推动 | 已完成首单、尚未形成稳定复购习惯的客户，用于推动第二笔订单 |
| VIP / High-Value | VIP / 高价值客户 | 消费金额或频次较高的核心客户群体 |
| VIP Customers (Shopify) | VIP 客户（Shopify） | 基于 Shopify 数据识别的高价值客户分群 |
| Win-Back Opportunities (Shopify) | 挽回机会客户（Shopify） | 基于 Shopify 数据识别、有流失风险或久未下单、适合唤醒营销的客户 |
| Active Repeat Customer | 活跃复购客户 | 近期有购买行为且已形成重复购买习惯的客户 |
| First-Time Buyer | 首次购买者 | 仅完成过首次购买的新客；当前为默认分群（Default），可绑定如「Order 5% - 1 per code」等折扣 |
| New Customer Welcome | 新客户欢迎 | 新注册或新加入品牌、尚未完成首单或处于欢迎流程中的客户 |

## 状态说明

| 状态（英文） | 中文 |
| --- | --- |
| Active | 活跃 |
| Processing | 处理中 |
| Inactive | 非活跃 |
