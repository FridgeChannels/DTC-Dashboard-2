## Current external blockers and certification gaps

- Production Supabase migrations and scheduled activation cannot be deployed with the current account permissions. Code and migration verification continue locally.
- The real 2026 Seller Central Coupon Bulk Template and representative current Promotion/Claim Code exports are not available. Synthetic/documented fixtures cover behavior, but Amazon-export compatibility cannot be finally certified.
- The PRD leaves a numeric Valid Interaction dwell threshold undefined. The safe MVP standard is a meaningful action event plus staff/bot/rapid-repeat exclusion; a page open alone never qualifies.
